# 遥测数据（Telemetry Data）

[English](README.md) | **中文**

卫星平台与载荷遥测，包括在轨计算实验的实测数据。

## [ACM MobiCom 2024 · BUPT-1 在轨计算数据集](https://github.com/OPEN-TianSuan/MobiCom24-SatelliteCOTS)

数据集包含 BUPT-1 立方星的平台遥测，以及 Atlas 200 DK 和 Raspberry Pi 4B 执行在轨计算任务时的实测数据。测量内容涵盖日照段与地影段的温度变化、太阳能发电功率和星上用电功率。

仓库提供遥测汇总 CSV、各实验的数据文件，以及用于数据处理和复现论文图表的 Python 脚本。

数据集包含 **10,117,299 条平台遥测记录**，覆盖 2023 年 3 月 22 日至 7 月 24 日。平台遥测汇集了太阳能供电、电池充放电和载荷用电的测量数据。实验数据还支持对比地面与在轨运行，以及不同负载和功率档位下的温度与能耗。

数据集涵盖 10 个测量项目，涉及载荷温度、卫星供电和在轨计算能效。

| 数据项目 | 测量内容 |
| --- | --- |
| 温度概况 | 有无计算任务时的表面温度 |
| 温度与功耗 | 不同 CPU、NPU 和功率档位下的温度与功耗 |
| 载荷过热 | Atlas 与 Raspberry Pi 在轨及地面推理的过热情况 |
| 升温速率 | 不同功率和负载条件下的升温速率 |
| 日照与地影 | 日照段与地影段的载荷温度对比 |
| 供电与用电概况 | 有无计算任务时的太阳能发电功率与星上用电功率 |
| 单圈轨道功率与电池充放电 | 单圈轨道内的功率变化和电池充放电曲线 |
| 长期能量变化 | 两周内的太阳能发电量和星上用电量 |
| 可用能量 | 相同时间窗口内的太阳能发电量与用电量对比 |
| 计算能效 | 地面与在轨的推理、图像分类和 JPEG 编码实验 |
